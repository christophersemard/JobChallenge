- présentation de profil et de compétences ;
- modal interactif ;
- slider ;
- cartes animées ;
- mise en page responsive.

## Consulter localement

Ouvrir index.html ou servir le dossier avec un serveur statique :

    python -m http.server 8000

Exercice de formation consacré à l'intégration CSS et aux interactions JavaScript.
